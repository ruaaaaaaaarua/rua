# 电力系统分析学习工作台

本次实施依据：用户已确认本轮讨论结论并要求直接修改项目、删去不需要的功能、改善审美。知识正文由用户后续填充。本地单用户应用，不在本次上线收费、账号系统或对外部署。

## 产品与边界

- 固定科目：电力系统分析。以拍照输入题目为入口，支持有答案和未作答图片。
- 共享知识骨架：稳定 ID、章节、别名、关系、Markdown 正文、来源、版本、草稿/已发布状态。初始只提供目录和空白正文模板，不虚构考试权威、考频和教材内容。
- 个人覆盖层：题目多对多挂载知识 ID，挂载可修正；公共知识不会被模型改写。低置信候选待确认，未匹配待归类。
- 知识检索固定发生在解题/聊天之前。只有已发布且有正文的条目可作为讲解依据，记录节点 ID 和版本；草稿不伪装命中。
- 学习事件记录可观察事实：照片已有答案的帮助情况未知、打开讲解、站内作答、复习作答。规则按原题复习，不估计掌握百分比、心理错因、页面阅读时长。
- 复习从个人历史题抽取，开始时隐藏答案，查看讲解后标记 assisted，提交只允许一次；延长间隔只依据有效复习结果。待确认/争议题不进入复习；纠错撤销受影响事件。
- 移除自动错因分析、变式/前置/深入生成、思路打标输入、多科目入口。旧数据保留为历史，不将旧诊断迁入新状态。

## 实现

复用 FastAPI、SQLite、React、现有 OpenAI-compatible 模型连接和图片上传。核心知识文件存放于 knowledge/，由 app/knowledge.py 服务读取；个人挂载与学习事件以新增表保存于原 SQLite。接口保持服务边界，可日后接入远程 MCP；此版本不声称本地知识文件保密或具备 SaaS 租户隔离。

UI：暖白纸面、深墨绿固定导航、细线和适量留白；学习台、知识库、复习三个完整页面；模型设置弹窗；Markdown 数学显示；移动端折叠菜单。知识详情同时呈现正文状态和个人题目挂载，空态诚实且有操作入口。

## 验收

以临时数据库测试知识发布门槛、稳定 ID 关联、解题检索上下文、未知作答不冒充独立、复习防答案泄漏/重复提交、修改后撤销、旧设置兼容、未匹配和知识空态。运行后端测试、前端测试、生产构建；浏览器检查桌面和手机关键流程。真实 API 准确率需用户模型验证。
