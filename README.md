# 电网学习助手

电脑端本地网页：上传已作答的整页图片，先看总览与简短反馈，再自主追问或验证。学习记录和模型设置保存在本机，相关内容通过 API 发给你指定的云端模型。

## 启动

macOS 双击 `start.command`。首次运行会在项目内建立 Python 环境并构建网页；需要 Python 3.9+、Node.js 22+ 和网络。当前开发环境已经安装依赖。

启动后访问 <http://127.0.0.1:8765>，保留启动的终端窗口。关闭服务可在该终端按 Ctrl+C。

也可以手动启动：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm --prefix web ci
npm --prefix web run build
.venv/bin/python -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8765
```

## 第一次使用

1. 打开“模型设置”，添加接口地址、模型名称和密钥。地址填到 API 基址（通常以 `/v1` 结尾），程序追加 `/chat/completions`。
2. 指定图片理解模型和主模型。需要时展开任务设置，单独指定解题诊断、交流、生成和复核模型。
3. 保存配置并测试连接。连接测试验证文本请求与结构化响应；真实识图能力需要通过上传测试。
4. 新建学习，上传已做过的 PNG、JPEG 或 WebP 图片。每张最多 12 MB，一次最多 12 张。
5. 先看整页反馈，再选题追问、看解析或主动练一道。知识状态在有效作答后积累，不提供手动修改掌握度。

“打开演示”只创建明确标注的预设样例，不调用模型，也不会混入真实知识状态。演示不用于评价模型准确率。

## 模型兼容范围

当前接入采用 OpenAI-compatible Chat Completions HTTP 协议，不依赖特定厂商 SDK。可配置支持此协议的模型服务，识图任务还必须支持 `image_url` 数据。不同服务商的模型名称、接入地址、结构化输出能力和配额，以其提供的实际接口为准。原生专有协议目前没有单独适配。

输出使用 JSON Schema 描述并在本地校验。接口连接成功不等于解题和诊断正确；变式展示前会再独立求解并检查，仍然允许用户提出异议并复核。

没有内置 API Key，不会自行扫描其他应用的密钥。真实云端效果须在你保存自己的配置后验证。

## 数据与备份

- 默认数据目录：项目下 `data/`。
- 数据库：`data/learning.sqlite3`，包括历史、学习证据及模型配置。
- 原图：`data/attachments/`。
- 可以通过环境变量 `GRID_LEARNING_DATA` 指定另一处本地目录。
- 密钥不会返回网页或写入普通日志，数据库和数据目录限制为当前系统用户访问。当前采用文件权限保护，并非数据库加密；备份中仍包含密钥，应按私人文件保管。
- 备份前停止服务，再复制整个数据目录。不要只在运行中复制 SQLite 主文件而遗漏 WAL 数据。
- 删除对话默认保留提炼后的证据摘要；可选择连同证据一起删除。清理原图后无法再对照原笔迹，相关记录会注明。

## 当前实现边界

本版本提供通用科目入口，并随题目建立章节、知识点与证据。知识名称通过规范化归并，复杂跨科概念关系仍依赖模型与用户的后续核验；没有预置权威全科知识图谱。

资料采用文字或少量截图按需补充；PDF 页面请先截图。没有完整题库、完整教材检索、自动每日计划、外部提醒、自动按价格切换模型或数学符号求解器。

## 开发与检查

```bash
.venv/bin/python -m pytest -q
npm --prefix web test
npm --prefix web run build
```

本地开发可分别运行后端和 `npm --prefix web run dev`；Vite 的 `/api` 代理指向 8765 端口。接口文档在 `/api/docs`。

自动测试采用注入的确定性模型及模拟 HTTP 服务验证流程、模型协议和证据规则，不伪装成真实模型效果测试。
